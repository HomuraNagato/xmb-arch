# XMB Arch

XMB Arch is an original PlayStation 3-inspired theme for Pegasus Arch. It uses
horizontal metadata collections, vertical game lists, a favorites home screen,
and a controller-oriented settings category.

## Requirements

- Pegasus Arch with the `api.actions` theme interface
- Qt 5 Graphical Effects
- A 16:9 display between 1280x720 and 3840x2160
- Game metadata containing `assets.tile`, `assets.box_front`, or `assets.poster`
  and optionally `assets.background`

Copy the theme to a Pegasus theme directory or install it with the Pegasus Arch
package, then select **XMB Arch** in Pegasus settings.

## Controls

- Left/Right: change collection
- Up/Down: select a game or setting
- Enter/Gamepad A: launch or activate
- F/Gamepad Y: toggle favorite
- Escape/Gamepad B: open the Pegasus menu

The visual design, wave rendering, icons, and sounds are original and do not
include Sony assets.

Category icons default to the frosted XMB treatment. Use **Settings → Category
icon style** to switch between Frosted, Color, and Solid variants.
